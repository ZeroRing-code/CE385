# Workshop 1

## ข้อที่ 1: แนะนำตัว (`ex1-profile.js`)
สร้างตัวแปรด้วย `const` เพื่อเก็บข้อมูลส่วนตัว 5 อย่าง ได้แก่ ชื่อเล่น รหัสนักศึกษา อายุ สาขาวิชา และจำนวนวิชาที่ลงทะเบียน

แสดงผลด้วย Template Literal และคำนวณปีที่จะจบจากนิพจน์ `${2569 + remainingYears}` โดยไม่ใช้การต่อข้อความด้วยเครื่องหมาย `+`


## ข้อที่ 2: ชนิดข้อมูลและ `typeof` (`ex2-types.js`)
สร้างตัวแปรให้ครอบคลุม 6 ชนิดข้อมูล ได้แก่ string, number, boolean, undefined, null และ array พร้อมแสดงค่าคู่กับชนิดข้อมูลด้วย `typeof`

สาธิตกรณีพิเศษของ `typeof null` ที่ได้ผลลัพธ์เป็น `"object"`, ตัวแปรที่ยังไม่กำหนดค่าซึ่งเป็น `"undefined"` และ `NaN` ที่เป็น `"number"`

แปลง `inputAge` และ `inputScore` เป็นตัวเลขก่อนคำนวณ ใช้ `.toFixed(1)` จัดรูปแบบทศนิยม และเปรียบเทียบความแตกต่างระหว่าง `inputAge === 20` กับ `Number(inputAge) === 20`


## ข้อที่ 3: เครื่องคิดเลขคะแนน (`ex3-calculator.js`)
คำนวณคะแนนรวมของ CE385 จากคะแนนดิบ โดยเก็บค่าเกณฑ์คงที่ไว้ในตัวแปร `const` เพื่อหลีกเลี่ยง Magic Numbers

คะแนน Workshop ใช้สูตร `(workshopRaw / FULL_WORKSHOP_RAW) * WORKSHOP_WEIGHT` จากนั้นคำนวณคะแนนรวม เปอร์เซ็นต์ และคะแนนที่ขาดจากเป้าหมาย 80 คะแนน

แสดงผลด้วย Template Literal และจัดรูปแบบทศนิยมด้วย `.toFixed(2)`


## ข้อที่ 4: ตัดเกรดจากคะแนน (`ex4-grade.js`)
ฟังก์ชัน `toGrade` แปลงคะแนนช่วง 0 ถึง 100 เป็นเกรดด้วย `if / else if`

ตรวจสอบข้อมูลก่อนตัดเกรด หากคะแนนอยู่นอกช่วงจะแสดงข้อความแจ้งเตือน และทดสอบด้วย `for...of` กับคะแนนตัวอย่าง 13 ค่า


## ข้อที่ 5: ระบบสั่งอาหาร (`ex5-switch.js`)
ฟังก์ชัน `getMenuPrice` และ `getSizeMultiplier` ใช้ `switch` เพื่อหาราคาอาหารตามเมนูและขนาด

ใช้ Fall-through รวมเมนูที่มีราคาเท่ากัน และมี `default` รองรับเมนูนอกระบบ

วนลูปคำนวณราคารวมตามสูตร ราคาเมนู × ตัวคูณขนาด × จำนวน พร้อมแสดงรายการและยอดรวม


## ข้อที่ 6: ระบบตรวจสอบสิทธิ์ (`ex6-login.js`)
ฟังก์ชัน `login` ตรวจสอบ Username/Password สถานะบัญชี อายุ และบทบาทตามลำดับความสำคัญ โดยคืนค่าข้อความแทนการแสดงผลภายในฟังก์ชัน

ใช้ตัวดำเนินการ `&&` และ `||` ในการตรวจสอบเงื่อนไข การตรวจ Username/Password ก่อนช่วยยืนยันตัวตนก่อนตรวจสิทธิ์ และป้องกันการเปิดเผยข้อมูลระบบแก่ผู้ที่ยังไม่ผ่านการยืนยันตัวตน
